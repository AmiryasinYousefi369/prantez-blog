# پرانتز — وبلاگ برنامه‌نویسی و وب‌دیزاین

سایت وبلاگ ساده و ایستا (بدون نیاز به هیچ فریم‌ورک یا بیلد)، آماده برای انتشار روی GitHub Pages.

## ساختار فایل‌ها

```
parantez/
├── index.html              صفحه‌ی اصلی
├── posts/                  مقالات
│   ├── ui-thinking-for-developers.html
│   ├── css-grid.html
│   ├── js-vs-ts.html
│   └── ux-principles.html
└── assets/
    ├── style.css
    └── script.js
```

## راه‌اندازی روی GitHub Pages

مراحل کامل در پاسخ چت توضیح داده شده؛ خلاصه‌اش:

1. یک ریپازیتوری جدید در گیت‌هاب بسازید.
2. تمام فایل‌های این پوشه را داخل ریپازیتوری قرار دهید (نه خود پوشه‌ی parantez، بلکه محتویاتش).
3. از تنظیمات ریپازیتوری، بخش Pages را باز کنید و شاخه‌ی main را به‌عنوان منبع انتخاب کنید.
4. بعد از چند دقیقه، سایت روی آدرسی شبیه به `https://username.github.io/repo-name/` در دسترس است.

## شخصی‌سازی

- متن بیوگرافی و لینک‌های تماس (ایمیل، گیت‌هاب، لینکدین) در `index.html` داخل بخش‌های `#about` و `#contact` هستند.
- رنگ‌ها و فونت‌ها در `assets/style.css`، بالای فایل، در بخش `:root` تعریف شده‌اند.
- برای افزودن مقاله‌ی جدید، یکی از فایل‌های داخل `posts/` را کپی و محتوایش را عوض کنید، بعد یک ردیف جدید به لیست مقالات در `index.html` اضافه کنید.
