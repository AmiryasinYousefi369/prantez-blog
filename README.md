# amiryasin.dev — پورتفولیوی شخصی

صفحه‌ی تک‌صفحه‌ای، ایستا و بدون نیاز به بیلد؛ آماده برای انتشار روی GitHub Pages.

## ساختار

```
amiryasin-site/
├── index.html
└── assets/
    ├── style.css
    └── script.js
```

## انتشار روی GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بساز (یا از همون ریپازیتوری قبلی prantez-blog استفاده کن).
2. محتویات این پوشه (نه خود پوشه) رو توی ریپازیتوری آپلود کن؛ یعنی `index.html` باید مستقیم توی ریشه‌ی ریپازیتوری باشه.
3. اگه از ریپازیتوری قبلی استفاده می‌کنی، فایل‌ها و پوشه‌ی `posts` قدیمی رو حذف کن تا با فایل‌های جدید قاطی نشن.
4. برو به Settings → Pages، شاخه‌ی main و پوشه‌ی root رو انتخاب کن (اگه قبلاً تنظیم کردی، لازم نیست دوباره انجامش بدی).
5. چند دقیقه صبر کن تا سایت آپدیت بشه.

## شخصی‌سازی

- بیوگرافی در `index.html` داخل بخش `#about`.
- لینک ایمیل/گیت‌هاب/لینکدین در فوتر (`#contact`) — الان پلیس‌هولدرند، حتماً عوضشون کن.
- نمونه‌کارهای بخش `#projects` الان محتوای نمونه‌اند؛ عنوان، توضیح، لینک (`href="#"`) و استک تکنولوژی هر کدوم رو با پروژه‌های واقعی خودت جایگزین کن.
- رنگ اصلی (بنفش) و فونت‌ها در `assets/style.css`، بخش `:root`.
