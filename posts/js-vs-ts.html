جاوااسکریپت 1405/06/02 · ۷ دقیقه مطالعه

جاوااسکریپت یا تایپ‌اسکریپت؛ کدام را انتخاب کنیم؟

تایپ‌اسکریپت جادو نیست؛ یک لایه‌ی اضافه روی جاوااسکریپت است که یک دسته از خطاها را زودتر نشان می‌دهد. سؤال واقعی این است که این لایه، کِی ارزشش را دارد.

هر بار که این سؤال پرسیده می‌شود، معمولاً جواب به یک بحث احساسی تبدیل می‌شود: «تایپ‌اسکریپت همه‌چیز را حل می‌کند» در برابر «تایپ‌اسکریپت فقط پیچیدگی اضافه می‌کند». واقعیت جایی وسط این دو است. تایپ‌اسکریپت، جاوااسکریپت را کند یا سریع نمی‌کند؛ چون در نهایت به همان جاوااسکریپت کامپایل می‌شود. کاری که انجام می‌دهد این است که قبل از اجرای کد، درباره‌ی شکل داده‌ها به شما هشدار می‌دهد.

چه چیزی واقعاً عوض می‌شود

فرض کنید تابعی دارید که یک آبجکت کاربر می‌گیرد و نام او را برمی‌گرداند. در جاوااسکریپت خالص:

function getName(user) {
  return user.fullName;
}

اگر جایی در کد، آبجکتی بدون فیلد fullName به این تابع پاس داده شود، تا وقتی برنامه اجرا نشود متوجه نمی‌شوید. حالا همین تابع در تایپ‌اسکریپت:

type User = {
  fullName: string;
  email: string;
};

function getName(user: User): string {
  return user.fullName;
}

حالا اگر جایی سعی کنید آبجکتی بدون fullName بفرستید، همان لحظه‌ی نوشتن کد، ویرایشگر به شما خبر می‌دهد؛ نه وسط استفاده‌ی کاربر واقعی از برنامه.

هزینه‌ی این امنیت

این امنیت رایگان نیست. باید تایپ‌ها را تعریف کنید، گاهی با کتابخانه‌هایی سروکار دارید که تایپ ندارند، و منحنی یادگیری اولیه‌ای هم وجود دارد؛ مخصوصاً وقتی generics وارد ماجرا می‌شوند. برای یک اسکریپت کوچک یا یک پروتوتایپ سریع، این هزینه معمولاً ارزشش را ندارد.

قانون کلی: هرچه پروژه بزرگ‌تر، تیم چندنفره‌تر و عمر پروژه طولانی‌تر باشد، سود تایپ‌اسکریپت بیشتر از هزینه‌اش می‌شود.

یک راه میانه

لازم نیست همه‌چیز یا سیاه باشد یا سفید. می‌شود یک پروژه‌ی جاوااسکریپتی را با JSDoc کمی تایپ‌دار کرد، بدون این‌که کل ابزار کامپایل عوض شود:

/**
 * @param {{ fullName: string }} user
 * @returns {string}
 */
function getName(user) {
  return user.fullName;
}

این روش، بخشی از مزایای تایپ‌اسکریپت را بدون تغییر کامل زیرساخت پروژه می‌دهد؛ گزینه‌ی خوبی برای پروژه‌های قدیمی‌تر که مهاجرت کامل به آن‌ها زمان‌بر است.

جمع‌بندی

تایپ‌اسکریپت را نه به‌عنوان یک ابزار «بهتر» بلکه به‌عنوان یک ابزار «مناسب برای موقعیت درست» ببینید. برای پروژه‌های کوچک و شخصی، جاوااسکریپت خالص کافی است. برای پروژه‌هایی که قرار است چند نفر روی آن‌ها کار کنند و سال‌ها زنده بمانند، تایپ‌اسکریپت معمولاً انتخاب بهتری است.
