چرا CSS Grid چیدمان صفحات وب را برای همیشه عوض کرد

قبل از Grid، چیدمان دو بعدی در وب یعنی چند تا float و یک عالمه هک. حالا با چند خط کد، هم ردیف و هم ستون را همزمان کنترل می‌کنیم.

تا چند سال پیش، چیدمان صفحات وب بیشتر با ترفند انجام می‌شد تا ابزار. از float برای چیدن ستون‌ها استفاده می‌کردیم، از position: absolute برای هم‌ترازی، و هر بار که طرح صفحه کمی پیچیده می‌شد، CSS به‌سرعت شلوغ می‌شد. Flexbox این وضعیت را بهتر کرد، اما Flexbox برای چیدمان یک‌بعدی ساخته شده؛ یعنی یا سطر را خوب می‌چیند، یا ستون را. CSS Grid اولین ابزاری بود که چیدمان دوبعدی، یعنی سطر و ستون با هم، را به‌شکل طبیعی حل کرد.

تفاوت Grid با Flexbox

ساده‌ترین راه برای فهمیدن تفاوت این دو، فکر کردن به جهت چیدمان است. Flexbox عناصر را در یک مسیر می‌چیند و هر عنصر بر اساس محتوایش جا می‌گیرد. Grid برعکس، اول یک شبکه از سطر و ستون تعریف می‌کند و بعد عناصر را داخل آن شبکه جا می‌دهد. برای همین Grid برای چیدمان کلی صفحه (هدر، منو کناری، محتوا، فوتر) مناسب‌تر است، و Flexbox برای چیدن عناصر داخل یک بخش کوچک، مثل یک نوار دکمه یا یک کارت.

یک قانون ساده: اگر داری چیدمان کل صفحه را طراحی می‌کنی، Grid را امتحان کن. اگر داری چند عنصر را داخل یک بخش کوچک می‌چینی، Flexbox معمولاً کافی است.

یک الگوی رایج: چیدمان اصلی صفحه

یکی از کاربردی‌ترین الگوهای Grid، ساختن چیدمان کلی یک صفحه با ناحیه‌های نام‌گذاری‌شده است:

.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar main";
  min-height: 100vh;
}

.sidebar { grid-area: sidebar; }
.header  { grid-area: header; }
.main    { grid-area: main; }

با همین چند خط، یک منوی کناری ثابت و یک بخش اصلی داریم که خودش هدر و محتوا دارد؛ بدون هیچ float یا موقعیت مطلقی. اگر بعداً بخواهیم چیدمان را در موبایل عوض کنیم، کافی است در یک media query دوباره grid-template-areas را تعریف کنیم، بدون تغییر در HTML.

وقتی محتوا نامنظم است

یکی از ویژگی‌های کمتر شناخته‌شده‌ی Grid، توانایی‌اش در چیدن آیتم‌های با اندازه‌ی نامنظم است؛ مثل یک گالری که بعضی عکس‌ها بزرگ‌تر از بقیه‌اند. با auto-fill و minmax می‌شود تعداد ستون‌ها را بدون هیچ media query‌ای واکنش‌گرا کرد:

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
  gap: 16px;
}

این یک خط، مرورگر را وادار می‌کند خودش تصمیم بگیرد چند ستون در عرض صفحه جا می‌شود؛ بدون این‌که ما نقطه‌های شکست را دستی تعریف کنیم.

جمع‌بندی

CSS Grid ابزاری نیست که جایگزین Flexbox شده باشد؛ مکمل آن است. یاد گرفتن این‌که کِی از کدام استفاده کنیم، یکی از آن مهارت‌هایی است که بعد از چند پروژه، به‌طور طبیعی دستمان می‌آید.
